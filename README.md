# blog-sender

- [`automation-engine/`](automation-engine/): a low-latency webhook automation engine (Zapier/Make-style) that turns blog "post published" webhooks into Telegram messages and photos. Fastify, BullMQ, Redis, PostgreSQL, Prisma. Start with [`automation-engine/README.md`](automation-engine/README.md).
- [`prompts/`](prompts/): the design prompt the engine was specified from.
